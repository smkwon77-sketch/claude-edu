# Claude 따라하기 교실 — (주)팬직

직원용 주소: https://smkwon77-sketch.github.io/claude-edu/

- `index.html` — 교육 페이지 (18단계, 연습용 모형 화면 포함)

## 고쳐서 다시 올리는 법
1. 원본 `직원교육\Claude_따라하기_교육.html` 을 고친다.
2. 묶기 스크립트를 다시 실행해 이 폴더의 `index.html` 을 새로 만든다.
3. 이 폴더에서 `git add . && git commit -m "내용 수정" && git push` — 1~2분 뒤 주소에 반영된다.
